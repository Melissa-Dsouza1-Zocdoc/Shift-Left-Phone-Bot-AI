### Suggested Missing Tests
- **LLM error during agent turn** - No coverage for `llm_node` raising `APIError`/timeout midway through generation; verify retry vs hard-break path.
- **Cancellation during handoff** - No test cancels `get_next_agent` partway and asserts cleanup; LiveKit cancellation tokens are easy to leak.
- **Concurrent tool events** - Two near-simultaneous tool events on the same agent — does ordering hold?
- **Hard break event PHI redaction** - When `HardBreakEvent` payload contains patient name/DOB, ensure it is scrubbed before logging.

### Improvement Suggestions / Irrelevant Tests
- **Heavy mocking** - Many tests instantiate `BaseAgent` subclasses with `patch("...load_prompt", return_value="instructions")` — consider a real fixture YAML so prompt-loader contract is also exercised.
- **Class abstractness duplication** - Three near-identical tests check abstract enforcement — collapse into one parametrized case.
- **Session mocking** - PropertyMock on `session` is repeated; extract a shared fixture for cleaner intent.
